============================================================
  SONIFICATION APP — HOW TO RUN
============================================================

REQUIREMENTS
------------
- Python 3.9 or newer
  Download from: https://www.python.org/downloads/
  IMPORTANT: During installation, check "Add Python to PATH"

- Speakers or headphones connected to your computer


FIRST-TIME SETUP & LAUNCH
--------------------------

  Windows:
    1. Unzip this folder anywhere on your computer
    2. Double-click  start.bat
    3. A browser tab will open automatically at http://localhost:8501

  Mac / Linux:
    1. Unzip this folder anywhere on your computer
    2. Open a Terminal inside the folder
    3. Run:  bash start.sh
    4. A browser tab will open automatically at http://localhost:8501

The first run will download and install the required packages (~1 minute).
Every run after that will start immediately.


USING THE APP
-------------
1. In the sidebar, choose "Internal demo" and click "Load internal demo"
   — or — choose "Upload TXT" and upload your own scenario file
2. Adjust sliders as desired
3. Click  ▶ Play  to start the audio
4. Click  ⏹ Stop  to stop


STOPPING THE APP
----------------
Press  Ctrl+C  in the terminal / command prompt window to shut it down.


TROUBLESHOOTING
---------------
- "Python is not installed": re-install Python and tick "Add Python to PATH"
- No sound: check your system volume and audio output device
- Browser doesn't open: manually go to http://localhost:8501
