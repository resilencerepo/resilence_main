# 🎧 Sonification App — How to Run

## 📋 Requirements

- **Python 3.9 or newer**  
  Download: https://www.python.org/downloads/  
  ⚠️ During installation, make sure to check **"Add Python to PATH"**

- Speakers or headphones connected to your computer


---

## 🚀 First-Time Setup & Launch

### 🪟 Windows
1. Unzip this folder anywhere on your computer  
2. Double-click `start.bat`  
3. A browser tab will open automatically at:  
   👉 http://localhost:8501  

### 🍎 Mac / 🐧 Linux
1. Unzip this folder anywhere on your computer  
2. Open a Terminal inside the folder  
3. Run:
   ```bash
   bash start.sh
   ```
4. A browser tab will open automatically at:  
   👉 http://localhost:8501  

💡 **Note:**  
- The first run will download and install required packages (~1 minute)  
- Subsequent runs will start instantly  


---

## 🎛️ Using the App

1. In the sidebar:
   - Select **"Internal demo"** and click **"Load internal demo"**  
     **OR**
   - Select **"Upload TXT"** to upload your own scenario file  

2. Adjust sliders as desired  

3. Click ▶ **Play** to start audio  

4. Click ⏹ **Stop** to stop  


---

## 🛑 Stopping the App

Press:

```bash
Ctrl + C
```

in the terminal / command prompt window  


---

## 🧰 Troubleshooting

- **"Python is not installed"**  
  → Reinstall Python and ensure *"Add Python to PATH"* is checked  

- **No sound**  
  → Check system volume and selected audio output device  

- **Browser doesn’t open automatically**  
  → Manually go to: http://localhost:8501  


---

## 📦 Notes

- Works locally in your browser  
- No internet connection required after first setup
