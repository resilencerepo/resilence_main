# 3D Print Files for Ultrasonic Device (UpnaLab Copyright)

This repository contains the 3D printable and laser-cut files for various components of the **Ultrasonic device**, developed as part of the **ReSilence** project by Abel Korinsky.

The **Board case design** included in this repository was specifically designed by **UpnaLab**.
